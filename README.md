# 딥러닝을 활용한 불량검출 시스템 - 팀 프로젝트
데이터의 불량을 검출하는 시스템

###  📌 주요 기능
- 딥러닝을 통해 객체 인식 및 불량 검출
- 1차 검출: LED와 서보모터로 정상/불량 구현
- 2차 검출: 무게 센서(로드셀) 구현
- 컨베이어 벨트 사용으로 자동화 시스템을 구현
- 관리자/회원 권한 별 홈페이지를 이용해 실시간 영상, 차트, 검출 현황표 확인 가능

### 역할 
- 딥러닝 데이터 셋 학습
- 서버간 통신 기능 구현
- 무게 센서 기능 구현

### 🔧 개발 환경
- AWS
- MySQL
- RaspiberryPi
- Flask
- Roboflow
- Python

PCB, 음료팩 데이터 셋 Flow Chart
1. 컨베이어 벨트 작동 시작 후 카메라로 이동해 객체 사진 수집
2. 불량-서보모터 작동, 빨간색 LED 점등, 정상- 초록색 LED 점등
3. 음료팩은 2차 검출로 무게를 측정해 설정 무게가 초과, 미만이면 서보 모터 작동
4. 모든 데이터 셋이 데이터베이스와 서버에 저장됨
